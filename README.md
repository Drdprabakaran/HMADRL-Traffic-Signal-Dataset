# HMADRL Urban Traffic Dataset

## Description
This repository contains a synthetic urban traffic dataset developed for research on:

"A Hierarchical Multi-Agent Deep Reinforcement Learning Framework for Scalable Urban Traffic Signal Coordination"

## Dataset Features

- Timestamp
- Intersection_ID
- Agent_ID
- Vehicle_Count
- Queue_Length
- Avg_Speed_kmph
- Waiting_Time_sec
- Arrival_Rate
- Departure_Rate
- Pedestrian_Count
- Current_Phase
- Green_Time_sec
- Yellow_Time_sec
- Red_Time_sec
- Weather
- Neighbor_Queue
- Regional_Congestion
- Action_Taken
- Reward
- Throughput

## Records
10,000
